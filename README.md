# FORTEX Seguridad Inteligente

Página web de FORTEX, empresa de seguridad inteligente de Mazatlán (proyecto escolar de Cultura Empresarial).

- Tienda en línea con carrito y agenda de instalación.
- Panel interno de pedidos en `#panel` (en esta versión los pedidos se guardan en el navegador de quien compra).

Página: https://roblescamposcarlos-beep.github.io/FORTEX_web/
